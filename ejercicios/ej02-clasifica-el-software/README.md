# Ej02 · Clasifica el software 🐍

**Apartado 1.1 · Software y hardware** · ⏱️ 20 min

> 🎯 Repasa los **tres tipos de software** (de sistema, de aplicación y de desarrollo) escribiendo un pequeño programa que los clasifique.

| Tipo | Para qué sirve | Ejemplos |
|---|---|---|
| **De sistema** | Gestiona el ordenador y permite que funcionen las demás aplicaciones | Windows, Linux, drivers |
| **De aplicación** | Resuelve una necesidad del usuario | Navegador, Word, Spotify, un juego |
| **De desarrollo** | Ayuda a crear, traducir, probar o mantener programas | VS Code, gcc, Git, depurador |

## Pasos

Abre [`clasificar.py`](clasificar.py). Verás comentarios `# PASO 1`, `# PASO 2`… Ve completando el código **debajo de cada comentario**.

Para ejecutarlo:

```bash
cd ejercicios/ej02-clasifica-el-software
python3 clasificar.py
```

## ✅ Comprueba

La salida debe ser esta:

```text
SISTEMA (3): Windows 11, Driver de la tarjeta gráfica, Linux Ubuntu
APLICACIÓN (4): Google Chrome, Spotify, Minecraft, LibreOffice Writer
DESARROLLO (4): Visual Studio Code, gcc, Git, Depurador GDB
Total: 11 programas
```

Haz commit: `git commit -am "Ej02: clasificación del software"`.
