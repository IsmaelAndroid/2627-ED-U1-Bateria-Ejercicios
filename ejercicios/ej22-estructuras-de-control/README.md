# Ej22 · Estructuras de control 🐍

**Apartado 1.5 · Estructuras de un programa** · ⏱️ 40 min

> 🎯 Usar las **tres estructuras de control** con las que se construye cualquier algoritmo: **secuencial**, **condicional** y **repetitiva**, en un programa que hace el boletín de notas de un grupo.

| Estructura | Qué hace | En Python |
|---|---|---|
| **Secuencial** | Una instrucción detrás de otra | líneas seguidas |
| **Condicional** | Elige un camino según una condición | `if` / `elif` / `else` |
| **Repetitiva** | Repite mientras se cumpla algo o para cada elemento | `for`, `while` |

## Pasos

Completa [`boletin.py`](boletin.py) siguiendo los pasos y ejecútalo. Al final te pedirá una nota por teclado:

```bash
cd ejercicios/ej22-estructuras-de-control
python3 boletin.py
```

Escribe primero una nota **no válida** (por ejemplo `12`) y después una válida (`7`).

## ✅ Comprueba

```text
Ana     8.5  Notable
Luis    4.2  Insuficiente
Marta   9.6  Sobresaliente
Pablo   6.4  Bien
Sara    5.0  Suficiente
Media del grupo: 6.74
Aprobados: 4 de 5
Nota del alumno nuevo (0-10): 12
Nota no válida, inténtalo otra vez.
Nota del alumno nuevo (0-10): 7
Alumno nuevo: 7.0  Notable
```

Después marca en [`RESPUESTAS.md`](RESPUESTAS.md) qué estructura has usado en cada parte.
